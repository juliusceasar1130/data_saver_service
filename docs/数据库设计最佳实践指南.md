# 数据库设计最佳实践指南

本文档总结了本项目数据库设计的核心理念与最佳实践，旨在指导后续业务开发及数据库维护。

## 1. 核心设计理念

### 1.1 语义化命名 (Semantic Naming)
**原则**：字段名应清晰表达业务含义，而非照搬技术代码。

*   **Bad**: `body_code` (仅表达它是代码)
*   **Good**: `body_type` (明确表达它是车型种类)
*   **Bad**: `flag_1`
*   **Good**: `black_roof_flag`

**价值**：降低理解成本，减少开发人员查阅文档的频率，同时让 AI 辅助工具更容易推理业务逻辑。

### 1.2 辅助表与混合模式 (Hybrid Mode for Dictionaries)
**原则**：不要硬编码字典数据，也不要完全依赖动态生成。

**实施方案**：
1.  **预置 (Pre-fill)**：在系统部署时，插入所有已知、标准的字典值（如标准车型、颜色）。
2.  **自动发现 (Auto-discovery)**：程序运行时若遇到未知代码，不报错丢弃，而是自动插入字典表，标记为 `is_defined = FALSE`。
3.  **人工补全 (Human-in-the-loop)**：运维人员定期查询未定义记录，补充描述信息。

**价值**：系统鲁棒性强（不崩不丢数据），同时保证数据最终的一致性和可读性。

### 1.3 面向 AI 的注释 (Comments for AI)
**原则**：数据库 Schema 是大模型理解业务的第一手资料。注释不仅要写给与其对接的程序员看，更要写给 AI 看。

**最佳实践**：
-   **表注释**：说明表的业务用途。
-   **字段注释**：
    -   **含义解释**：不仅仅是翻译，而是解释业务逻辑（如 "1=返工车"）。
    -   **数据来源**：说明数据从何处提取（如 "从30字符第26位提取"），这有助于 AI 反推数据流。
    -   **关联关系**：明确指出外键关系（如 "关联 vehicle_body_types 表"）。

```sql
-- 优秀注释示例
rework_flag CHAR(1) NOT NULL 
COMMENT '返工车标志位，从30字符数据的第27位提取，0=正常车辆（一次喷涂），1=返工车，2=黑顶的第二次喷涂'
```

## 2. 常见问题解答 (FAQ)

### Q: 为什么要用辅助表，直接存代码不行吗？
**A**: 直接存代码会导致数据分析困难。例如查询 "白色车" 时，如果只有 `color_code='2LA1'`，AI 或分析师必须知道 `2LA1` 代表白色。有了辅助表，可以直接 JOIN 查询 `WHERE color_name LIKE '%白%'`，大大提升了数据的可用性和 AI 交互能力。

### Q: 为什么 raw_data 也要存？
**A**: 它是数据源的"真理"。如果解析逻辑有 Bug，或者未来需要提取被我们忽略的预留字段（如 `reserved_1`），我们可以通过 `raw_data` 重新解析历史数据，实现无损回溯。

### Q: 标志位字段从二值（0/1）扩展到多值（0/1/2）需要注意什么？
**A**: 当业务需求变化，标志位从简单的是/否扩展到多种状态时：
1. **更新注释**：必须在字段注释中明确列出所有可能的值及其含义（如 `0=正常，1=返工，2=黑顶二次喷涂`）
2. **考虑字典表**：如果状态超过 3 种，或者状态含义可能频繁变化，建议改用字典表管理
3. **查询兼容性**：确保现有的查询逻辑能正确处理新增的状态值
4. **大模型理解**：详细的枚举式注释能帮助 AI 准确理解每个状态的业务含义

## 3. Python 实现参考

处理混合模式字典的核心逻辑示例：

```python
def get_or_create_term(cursor, table, code_field, code_value, name_field):
    """
    通用混合模式处理函数
    :param table: 表名 (e.g., 'vehicle_body_types')
    :param code_field: 代码字段名 (e.g., 'body_type')
    :param code_value: 代码值 (e.g., 'UNK01')
    :param name_field: 名称字段名 (e.g., 'type_name')
    """
    # 1. 尝试查询
    cursor.execute(f"SELECT id FROM {table} WHERE {code_field} = %s", (code_value,))
    result = cursor.fetchone()
    
    if result:
        return result[0]
    
    # 2. 不存在则自动创建
    print(f"⚠️ 发现未知代码: {code_value}，自动记录到 {table}")
    cursor.execute(
        f"""INSERT INTO {table} ({code_field}, {name_field}, is_defined, first_seen) 
            VALUES (%s, %s, %s, %s)""",
        (code_value, f"未定义-{code_value}", False, datetime.now())
    )
    return cursor.lastrowid
```
