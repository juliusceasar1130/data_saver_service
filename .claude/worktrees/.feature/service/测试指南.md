# WebSocket服务器测试指南

**修改时间：2025年9月1日14点05分**

## 快速测试步骤

### 1. 启动WebSocket服务器

**Windows用户（推荐）：**
```cmd
cd service
双击运行 start_server.bat
```

**Python直接运行：**
```bash
# 进入service目录
cd service

# 安装依赖
pip install -r requirements.txt

# 启动服务器
python websocket_server.py
```

### 2. 启动前端应用

```bash
# 确保在项目根目录（不是service目录）
npm run dev
# 或
npm start
```

### 3. 测试连接

1. 打开浏览器访问前端应用（通常是 `http://localhost:5173`）
2. 点击"连接服务器"按钮
3. 观察连接状态变为"已连接"

### 4. 验证功能

**检查项目：**
- ✅ WebSocket连接成功
- ✅ 心跳统计正常增长
- ✅ 设备点位数据开始接收
- ✅ 表格中显示模拟数据
- ✅ 数据值定期更新（2-5秒间隔）

**预期结果：**
- 连接状态：绿色"已连接"
- 监控点位：100个设备
- 数据更新：每个设备点位定期收到新数据
- 更新次数：持续增长

## 故障排除

### 连接失败
1. 确认WebSocket服务器已启动（在service目录中运行）
2. 检查端口8088是否被占用
3. 确认防火墙未阻止连接
4. 验证当前工作目录是否正确

### 数据未更新
1. 查看服务器控制台是否有推送日志
2. 检查前端是否发送了订阅请求
3. 确认网络连接稳定

### 性能问题
1. 调整数据推送频率（修改service/server_config.py）
2. 减少监控设备数量
3. 检查系统资源使用情况
