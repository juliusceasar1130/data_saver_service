# WebSocket工业数据采集系统使用指南

**修改时间：2025年9月1日14点05分**  
**修改内容：创建用户使用指南文档**

## 系统概述

本系统是一个基于Web的工业数据采集演示平台，通过WebSocket技术实现与PLC设备的实时通信，可以监控和展示工业生产线上的各种传感器数据。

### 功能区域说明

#### 1. 系统标题栏
- **系统标题**：显示"WebSocket工业数据采集演示系统"
- **连接状态指示器**：
  - 🟢 **已连接**：WebSocket连接正常
  - 🟡 **连接中**：正在建立连接
  - 🔴 **未连接**：连接断开或未建立

#### 2. 控制面板

##### 连接控制区域
- **服务器地址输入框**：
  - 默认值：`172.21.12.73/ws/emosweb`
  - 可手动修改为其他WebSocket服务器地址
  - 连接状态下禁用编辑

- **连接服务器按钮**：
  - 建立WebSocket连接
  - 连接成功后自动订阅设备数据
  - 连接中或已连接时禁用

- **断开连接按钮**：
  - 主动断开WebSocket连接
  - 停止数据接收和心跳
  - 未连接时禁用

##### 连接统计区域
实时显示连接相关的统计信息：
- **心跳次数**：已发送的心跳包数量
- **收到消息**：接收到的数据消息总数
- **监控点位**：当前配置的设备监控点位数量
- **连接时长**：本次连接的持续时间（格式：HH:MM:SS）

#### 3. 数据展示区域

##### 数据表格
- **序号**：数据条目的编号
- **接收时间**：数据到达系统的时间戳
- **PLC设备**：数据来源的PLC设备名称
- **数据点位标签**：具体的设备数据点标识
- **数据值**：设备传感器的实时数值
- **消息类型**：数据消息的类型标识

##### 操作按钮
- **清空数据**：清除表格中的所有数据记录
- **刷新**：重新发送设备订阅请求

## 操作流程

### 1. 系统启动
1. 确保Node.js环境已安装
2. 运行启动脚本：
   - Windows：双击 `start.bat`
   - Linux/Mac：执行 `./start.sh`
3. 等待浏览器自动打开系统界面

### 2. 连接WebSocket服务器
1. 检查服务器地址是否正确
2. 点击"连接服务器"按钮
3. 观察连接状态指示器变化：
   - 🟡 连接中... → 🟢 已连接

### 3. 监控数据接收
1. 连接成功后，系统会自动：
   - 发送设备点位订阅请求
   - 开始接收实时数据
   - 启动心跳保活机制

2. 观察数据表格：
   - 新接收的数据会自动添加到表格顶部
   - 表格最多显示100条记录（自动删除旧数据）

### 4. 数据管理
- **查看详细信息**：数据点位标签较长时，鼠标悬停可查看完整内容
- **清空历史数据**：点击"清空数据"按钮
- **重新订阅**：点击"刷新"按钮重新发送订阅请求

### 5. 断开连接
1. 点击"断开连接"按钮
2. 系统会：
   - 关闭WebSocket连接
   - 停止心跳保活
   - 更新连接状态为"未连接"

## 设备数据说明

### 当前监控的设备点位

系统预配置了10个L3FKT1系列PLC设备的1C工艺段数据点位：

```
设备: L3FKT1
工艺段: 1C
传感器系列: 18AS
监控点位: ST[1] 到 ST[10]
数据类型: M1003_BodyID
```

### 数据点位格式说明

```
.L3FKT1_1C_18AS_1C045RO_1C045ROFG1.ST[n].IL.SD.M1003_BodyID
│      │  │   │               │    │  │  │  │
│      │  │   │               │    │  │  │  └─ 数据标识
│      │  │   │               │    │  │  └─── 状态描述
│      │  │   │               │    │  └─────── 接口层
│      │  │   │               │    └────────── 状态编号[n]
│      │  │   │               └─────────────── 功能组标识
│      │  │   └──────────────────────────────── 设备编号
│      │  └───────────────────────────────────── 传感器系列
│      └──────────────────────────────────────── 工艺段标识
└─────────────────────────────────────────────── PLC设备名
```

### 数据值含义

接收到的数据值通常表示：
- **0 或空值**：传感器未检测到信号
- **非零值**：传感器检测到相应的工件或状态
- **字符串**：设备状态描述或标识信息

## 故障处理

### 常见问题及解决方案

#### 1. 无法连接WebSocket服务器

**现象**：点击连接后状态一直显示"连接中"或直接变为"未连接"

**可能原因**：
- WebSocket服务器未启动
- 服务器地址错误
- 网络连接问题
- 防火墙阻止连接

**解决方法**：
1. 检查服务器地址是否正确
2. 确认WebSocket服务器是否正常运行
3. 检查网络连接
4. 查看浏览器控制台错误信息

#### 2. 连接建立但无数据接收

**现象**：连接状态显示"已连接"但数据表格为空

**可能原因**：
- 设备未发送数据
- 订阅请求失败
- 数据格式不匹配

**解决方法**：
1. 点击"刷新"按钮重新订阅
2. 检查浏览器控制台是否有数据接收日志
3. 确认PLC设备是否正常运行

#### 3. 连接频繁断开

**现象**：连接状态经常从"已连接"变为"未连接"

**可能原因**：
- 网络不稳定
- 服务器负载过高
- 心跳机制失效

**解决方法**：
1. 检查网络稳定性
2. 重新建立连接
3. 联系服务器管理员

#### 4. 页面加载缓慢或卡顿

**现象**：界面响应慢，数据表格滚动不流畅

**可能原因**：
- 数据量过大
- 浏览器性能不足
- 内存使用过多

**解决方法**：
1. 定期清空历史数据
2. 关闭其他占用资源的程序
3. 使用更高性能的浏览器

### 技术支持

如果遇到无法解决的问题：

1. **记录错误信息**：
   - 打开浏览器开发者工具（F12）
   - 查看Console标签页的错误信息
   - 截图保存相关错误信息

2. **收集系统信息**：
   - 操作系统版本
   - 浏览器类型和版本
   - 网络环境描述
   - 具体操作步骤

3. **联系技术支持**：
   - 提供详细的错误描述
   - 附上错误截图和日志
   - 说明问题复现步骤

## 系统要求

### 硬件要求
- **处理器**：1GHz或更高
- **内存**：2GB RAM或更高
- **存储**：100MB可用磁盘空间
- **网络**：支持WebSocket的网络环境

### 软件要求
- **操作系统**：Windows 7+, macOS 10.12+, Linux
- **Node.js**：16.0或更高版本
- **浏览器**：
  - Chrome 80+
  - Firefox 75+
  - Safari 13+
  - Edge 80+

### 网络要求
- **带宽**：建议1Mbps或更高
- **延迟**：建议100ms以下
- **协议支持**：WebSocket (ws://) 或 WebSocket Secure (wss://)
