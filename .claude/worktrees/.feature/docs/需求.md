# 每完成一步，都必须更新progress.md文件，并提前阅读下一步任务

# 步骤0
 -查看任务清单progress.md，确认当前任务是否完成，完成则继续下一个任务
 -如果没有，则在充分理解需求前提下，模仿例子和当前任务 生成笔记progress.md文件


# 步骤1
 - 访问上文输入的网址，不能截取部分
 - 获取网页内容，必须完成全部内容，除了和文章中无关的内容，如广告，图片，导航栏，无关的信息
 - 保存xxx-org.md
# 步骤2
 - 根据原文xxx-org.md翻译成中英文对照版
 - 保存在xxx-en-cn.md
 # 步骤3
 - 提取xxx-en-cn.md中的中文部分
 - 保存为xxx-cn.md
