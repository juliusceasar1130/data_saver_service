# WebSocket数据监控系统 - 界面模式对比说明

**修改时间：** 2025年9月16日  
**修改内容：** 更新界面模式设计，优化用户体验和功能布局

---

## 概述

WebSocket数据监控系统支持两种界面显示模式，通过 **Ctrl+M** 快捷键进行切换：
- **正常模式** (`showControlPanel = true`)：数据看板 + 完整数据表格
- **隐藏模式** (`showControlPanel = false`)：数据看板 + 8区域监控

两种模式都包含数据看板，但后续内容不同，适用于不同的监控场景和用户需求。

### 核心特点

- **Purple雪橇数量：** 数据值>5999时的雪橇数量总和

- **在线设备数量：** 当前连接状态为'online'的设备数
- **在线设备率：** 在线设备占总设备的百分比

#### **📋 完整表格视图**
- **基础列：** 序号、PLC设备、滚床编号、数据值、雪橇数量、连接状态、最后更新
- **高级列：** 数据点位标签、数据质量、更新次数、Factor、Weight、消息类型、区域、位置序号
- **显示策略：** 所有列始终显示，无条件隐藏机制
- **数据处理：** 完整的业务逻辑和计算功能

#### **🎨 视觉特点**
- 传统仪表盘风格
- 数据概览一目了然
- 适合管理层查看整体状况
- 卡片式数据看板突出关键指标

## 🔄 切换机制

### 切换逻辑
```javascript
const toggleUIVisibility = () => {
  showControlPanel.value = !showControlPanel.value
  
  ElMessage.info(`UI切换: ${showControlPanel.value ? '显示' : '隐藏'}详细面板`)
}
```

### 键盘快捷键
- **快捷键：** `Ctrl + M`
- **功能：** 在正常模式和隐藏模式间切换
- **响应：** 实时切换，无需刷新页面

## 📊 响应式设计

### 桌面端 (>1200px)
- **正常模式：** 4个看板并排显示
- **隐藏模式：** 8区域采用1-2-1-3-1网格布局

### 平板端 (768px-1200px)
- **8区域：** 自动调整为2列6行布局
- **Area0和Area7：** 跨列居中显示
- **统一容器：** 高度调整为 `calc(100vh - 200px)`

### 手机端 (<768px)
- **8区域：** 单列垂直排列
- **Area0-Area7：** 垂直排序显示
- **统一容器：** 高度调整为 `calc(100vh - 150px)`
- **字体优化：** 更小的字体确保内容可读

## 🚀 开发指导

### 数据一致性原则
1. **统一数据源：** 两种模式使用相同的 `deviceData`
2. **相同计算逻辑：** 雪橇数量、状态判断等保持一致
3. **数据看板共享：** 两种模式显示相同的全局统计信息
4. **完整列信息：** 所有表格始终显示完整的列信息

### 布局扩展建议
1. **区域数据定制：** 可根据 `area` 字段为不同区域显示对应设备
2. **主题切换：** 可为两种模式设置不同的主题色彩
3. **区域配置：** Area0-7的内容可配置化管理
4. **Area0特色：** 可进一步定制Area0的特殊显示样式和交互

### 性能优化要点
1. **虚拟滚动：** 大数据量时考虑实现虚拟滚动
2. **懒加载：** 区域数据可按需加载
3. **缓存机制：** 切换模式时保持数据状态

### 用户体验优化
1. **切换动画：** 可添加平滑的过渡动画
2. **状态记忆：** 记住用户的模式偏好
3. **快捷操作：** 提供更多键盘快捷键

## 🎯 适用场景

### 正常模式适用于：
- **管理层监控：** 需要查看整体数据概览和详细分析
- **数据分析：** 需要完整表格进行深度数据分析
- **报告展示：** 适合会议或汇报场景
- **传统习惯：** 习惯传统表格界面的用户
- **详细信息查看：** 需要查看所有设备详细信息

### 隐藏模式适用于：
- **操作员监控：** 按区域分工的生产现场（支持8区域分工）
- **分区管理：** 不同区域有不同责任人（Area0-7独立管理）  
- **现场巡检：** 快速查看各区域设备状态
- **移动友好：** 在平板或手机上使用
- **专注监控：** 只关注区域数据和核心指标
- **特殊监控：** Area0区域可用于特殊或重点设备监控

---

## 📝 总结

两种模式各有优势，通过 `Ctrl+M` 快捷键可以灵活切换：

- **正常模式：** 数据看板 + 完整数据表格，适合详细分析和管理监控
- **隐藏模式：** 数据看板 + 8区域监控，适合分区监控和移动使用

两种模式都保留数据看板，确保核心指标的可见性。开发时应保持数据一致性，确保用户能够无缝切换使用。

**核心设计理念：** 统一数据源，双重展示模式，满足不同用户角色和使用场景的监控需求。

**优化成果：** 取消复杂的列显示控制，简化界面逻辑，提升用户体验。

**8区域扩展成果：** 新增Area0区域支持，完整8区域监控能力，紫色主题突出显示，响应式布局全面适配。
