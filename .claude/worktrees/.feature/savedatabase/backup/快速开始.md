# 数据保存服务 - 快速开始指南

**修改时间：2025年9月1日14点05分**  
**修改内容：创建快速开始指南**

## 三步启动服务

### 步骤1：安装依赖

```bash
cd savedatabase
pip install -r requirements.txt
```

### 步骤2：确保前置服务运行

1. **WebSocket 服务器**（在 `service` 目录）
   ```bash
   cd ../service
   python websocket_server.py
   ```

2. **MySQL 数据库服务**
   - 确保 MySQL 服务正在运行
   - 确保数据库 `production_record` 已创建
   - 确保表 `production` 已创建

### 步骤3：启动数据保存服务

**Windows:**
```bash
start_data_saver.bat
```

**Linux/Mac:**
```bash
chmod +x start_data_saver.sh
./start_data_saver.sh
```

或直接运行：
```bash
python data_saver_service.py
```

## 查看保存的数据

连接到 MySQL 数据库，查询数据：

```sql
USE production_record;

-- 查看最新保存的数据
SELECT * FROM production ORDER BY id DESC LIMIT 10;

-- 统计保存的数据量
SELECT COUNT(*) as total FROM production;

-- 按标签统计
SELECT tag, COUNT(*) as count FROM production GROUP BY tag;
```

## 停止服务

按 `Ctrl+C` 停止服务

## 常见问题

**Q: 提示无法连接到 WebSocket 服务器？**  
A: 确保 WebSocket 服务器已启动，检查地址和端口配置。

**Q: 提示数据库连接失败？**  
A: 检查 MySQL 服务是否运行，检查数据库配置是否正确。

**Q: 没有数据保存？**  
A: 检查 WebSocket 服务器是否在推送数据，查看日志文件获取详细信息。

## 日志文件

服务运行日志保存在：`data_saver_service.log`

查看日志：
```bash
# Windows
type data_saver_service.log

# Linux/Mac
tail -f data_saver_service.log
```
