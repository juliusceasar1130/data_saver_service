# 雪橇数量计算逻辑优化说明

**修改时间**: 2025年9月11日  
**版本**: v2.0.0  
**适用系统**: WebSocket工业数据采集系统

## 概述

本文档详细说明了雪橇数量计算逻辑的优化更新，主要针对 `factor` 字段格式变更和计算规则的完善。

## 背景

### 原有计算逻辑
- `factor` 字段为简单数值格式（如 `"4"`）
- 雪橇数量计算公式：`雪橇数量 = 1 × factor`
- `weight=1` 时的特殊处理：`雪橇数量 = 1`

### 优化需求
根据 `优化3.md` 的要求，需要支持更精细的计算控制：
- `factor` 字段改为对象格式：`{"norm": "4", "e5": "3"}`
- 根据数据值大小选择不同的系数
- 完善数据看板统计逻辑

## 新的计算逻辑

### 1. Factor 字段格式更新

**旧格式**：
```json
{
  "factor": "4"
}
```

**新格式**：
```json
{
  "factor": {
    "norm": "4",
    "e5": "3"
  }
}
```

### 2. 雪橇数量计算规则

按照以下优先级顺序计算：

#### 优先级1（最高）：Weight 特殊处理
```
当 weight = 1 且 数据值 < 5999 时：
雪橇数量 = 1
```

#### 优先级2：基于数据值的 Factor 选择
```
当 数据值 > 5999 时：
雪橇数量 = 1 × factor.e5

当 数据值 ≤ 5999 时：
雪橇数量 = 1 × factor.norm
```

#### 优先级3：异常处理
```
当数据无效或 factor 格式错误时：
雪橇数量 = 0
```

### 3. 具体实现逻辑

```javascript
/**
 * 计算雪橇数量 - 支持factor对象格式
 * @param {Object|string|number} factor - 系数值对象 {norm: "4", e5: "3"} 或数值
 * @param {string|number} value - 数据值
 * @param {string|number} weight - 权重值
 * @returns {number} 雪橇数量
 */
const calculateSkidCount = (factor, value, weight) => {
  const numValue = parseFloat(value)
  const weightNum = parseFloat(weight || 0)
  
  // 数据值无效时返回0
  if (isNaN(numValue) || numValue <= 0) {
    return 0
  }
  
  // 优先级1：weight=1且数据值<5999时，雪橇数量=1
  if (weightNum === 1 && numValue < 5999) {
    return 1
  }
  
  // 处理factor对象格式
  if (typeof factor === 'object' && factor !== null) {
    if (numValue > 5999) {
      // 数据值>5999时，使用factor.e5
      const factorE5 = parseFloat(factor.e5 || 0)
      return isNaN(factorE5) ? 0 : 1 * factorE5
    } else {
      // 数据值<=5999时，使用factor.norm
      const factorNorm = parseFloat(factor.norm || 0)
      return isNaN(factorNorm) ? 0 : 1 * factorNorm
    }
  }
  
  // 兼容旧格式：factor为数值
  const factorNum = parseFloat(factor)
  return isNaN(factorNum) ? 0 : 1 * factorNum
}
```

## 数据看板统计优化

### 1. Purple雪橇数量（数据值>5999）
```javascript
const purpleSkidCount = computed(() => {
  return deviceData.value.reduce((total, row) => {
    if (row.hasData && row.value && row.factor) {
      const numValue = parseFloat(row.value)
      
      if (!isNaN(numValue) && numValue > 5999) {
        // 使用factor.e5进行计算
        if (typeof row.factor === 'object' && row.factor.e5) {
          const factorE5 = parseFloat(row.factor.e5)
          return total + (isNaN(factorE5) ? 0 : 1 * factorE5)
        }
        // 兼容旧格式
        const factorNum = parseFloat(row.factor)
        return total + (isNaN(factorNum) ? 0 : 1 * factorNum)
      }
    }
    return total
  }, 0)
})
```

### 2. 常规雪橇数量（数据值≤5999）
```javascript
const normalSkidCount = computed(() => {
  return deviceData.value.reduce((total, row) => {
    if (row.hasData && row.value) {
      const numValue = parseFloat(row.value)
      
      if (!isNaN(numValue) && numValue <= 5999 && numValue > 0) {
        // weight=1时优先级最高
        if (row.weight && parseFloat(row.weight) === 1) {
          return total + 1
        } else if (row.factor) {
          // 使用factor.norm进行计算
          if (typeof row.factor === 'object' && row.factor.norm) {
            const factorNorm = parseFloat(row.factor.norm)
            return total + (isNaN(factorNorm) ? 0 : 1 * factorNorm)
          }
          // 兼容旧格式
          const factorNum = parseFloat(row.factor)
          return total + (isNaN(factorNum) ? 0 : 1 * factorNum)
        }
      }
    }
    return total
  }, 0)
})
```

## 兼容性说明

### 1. 向后兼容
- 系统完全兼容旧的数值格式 `factor: "4"`
- 新旧格式可以在同一配置文件中混用
- 不会影响现有数据的正常显示和计算

### 2. 迁移建议
- 建议使用转换工具将旧配置文件升级为新格式
- 新增配置统一使用对象格式
- 逐步替换生产环境中的旧格式配置

## 配置文件更新

### 推荐配置格式
```json
{
  "id": "",
  "type": "advise",
  "plc": "L3FUB2",
  "tag": ".L3FUB2_1A_1A010RB_1A010RB.IL.SD.I1030_RBDataSkidNo",
  "factor": {
    "norm": "4",
    "e5": "3"
  },
  "RBindex": "1A010RB",
  "weight": 0
}
```

### 字段说明
- **factor.norm**: 常规系数，用于数据值≤5999时的计算
- **factor.e5**: 高值系数，用于数据值>5999时的计算  
- **weight**: 权重值，当值为1且数据值<5999时，雪橇数量强制为1
- **RBindex**: 滚床编号，用于标识和显示
