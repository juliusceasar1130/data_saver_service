## 规则
carbody_history 表格中 MDS_DATA 字段 提取新字段为：

| 字段                | 位置    |
| ----------------- | ----- |
| `vehicle_id`      | 31-44 |
| `body_type`       | 45-49 |
| `platform_code`   | 51-53 |
| `color_code`      | 59-62 |
| `black_roof_flag` | 137   |
| `rework_flag`     | 139   |
| `reserved_1`      | 138   |
| `reserved_2`      | 140   |
